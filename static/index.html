info About AI Document Summarizer

dataset Dataset Used

Trained on the CNN / DailyMail (v3.0.0) benchmark dataset consisting of ~287,000+ training pairs, 13,368 validation pairs, and 11,490 test samples.

CNN/DailyMail 3.0.0 287K+ Training Pairs Multi-Sentence Highlights

psychology Model Architecture

Powered by a fine-tuned T5 (Text-to-Text Transfer Transformer) model employing an Encoder-Decoder architecture with multi-head self-attention.

  • Input Prefix: summarize: <context> <text>
  • Decoding Strategy: Beam Search (k=4) with length penalty (1.2) and 3-gram repetition penalty
  • Optimization: AdamW (LR: 3e-5) with FP16 Mixed-Precision
  • Evaluation: ROUGE-1, ROUGE-2, and ROUGE-L

account_tree Processing & Extraction Pipeline

  • Document Support: PDF (PyMuPDF), Word DOCX (python-docx), TXT, and Markdown
  • OCR Fallback: Tesseract OCR + Poppler for scanned documents/images
  • Section Intelligence: Context-aware chunking with heading preservation for documents of any length
  • Two-Level Synthesis: Section-by-section extraction followed by hierarchical summary generation
